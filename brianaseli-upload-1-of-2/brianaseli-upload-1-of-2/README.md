# Brian Aseli — The Most Bankable Host

Official personal-brand and booking website for Brian Aseli: host, master of ceremonies and moderator, Nairobi.

- `npm install && npm run dev` — local preview
- `npm run build && npm run check` — production build and checks
- **Start here:** `HANDOVER.md` (updating content, enquiry destination, deployment)
- **Research:** `research/research-audit.md`, `research/facts-to-confirm.md`, `research/source-register.csv`
- **Strategy:** `docs/brand-strategy.md`, `docs/content-architecture.md`
- **Content data:** `data/` — only entries with `"publish": true` in `media-library.json` reach the site.

Built with Astro (static output), self-hosted Sora / Manrope / Instrument Serif fonts, no analytics or cookies.
